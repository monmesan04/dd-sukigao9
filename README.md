# 株式会社DD 好き顔9選メーカー

スマホ向けのファン制作Webメーカーです。

## 使い方

1. `images` フォルダに参加メンバーの画像を入れる
2. ファイル名は `m00.jpg` ～ `m50.jpg`
3. GitHubにこの4点をアップロード
   - `index.html`
   - `style.css`
   - `script.js`
   - `images/`
4. GitHubリポジトリの Settings → Pages → Deploy from a branch → main / root を選択
5. 発行されたURLを開く

## 画像について

画像は同梱していません。本人写真を使用する場合は、利用規約・権利関係を確認したうえで、使用可能な画像を用意してください。
画像がない場合も、名前の頭文字を表示してメーカー自体は動作します。

## 現在の仕様

- 51人
- 予選：ランダムな2〜4人を複数回表示し、複数選択
- 本選：上位18人を3ラウンド比較
- 最終戦：上位候補を再比較
- 決勝：完全二択
- TOP9を表示
- 途中経過はブラウザのlocalStorageに保存
- 結果テキストをコピー可能

非公式のファン制作物です。株式会社DD、各グループ、各権利者とは関係ありません。
